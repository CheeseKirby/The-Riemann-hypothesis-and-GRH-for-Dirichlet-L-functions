# 翻译与排版流程说明（PIPELINE）

本文档记录这部 1545 页数学书中文全译的完整流程、使用的中间数据与校验方法，供复核与复现参考。

## 0. 总览

```
原书 PDF (1545 页)
   │
   ├─ 1. 逐页文本层提取 + 逐页渲染页面图像 (144 dpi, 1224×1584 PNG)
   │
   ├─ 2. 结构识别：目录、部分、41 章、附录、Lean 索引、参考文献 → 237 个翻译单元
   │
   ├─ 3. 编写《翻译规范》与《数学术语与语料库》（先于翻译）
   │
   ├─ 4. 并行翻译：每个单元 = 读规范 → 读原文 → 逐页看图核对公式 → 写 LaTeX 译文 → 自检
   │
   ├─ 5. 统稿：术语统一、章节标题统一、清理多余符号、修复数学定界符
   │
   ├─ 6. 质检：页码覆盖 / 公式定界符平衡 / 无英文残留 / 抽样复审 20 单元
   │
   └─ 7. 排版：按单元分块 MathJax 渲染 → Edge 打印 PDF → 合并 + 目录/索引/参考文献
```

## 1. 解析与页面图像

原书由 LaTeX（xdvipdfmx）生成。PDF 文本层在公式方面不可靠，常见问题包括：

| 文本层 | 实际含义 |
| --- | --- |
| `X`（字号偏大） | $\sum$ |
| `Z`（字号偏大） | $\int$ |
| `6=` | $\neq$ |
| `∈{/` | $\notin\{$ |
| `` ` `` | $\ell$ |
| 分子一行、分母一行 | 分式 |
| `\ufffe` / 私有区字符 | 断行连字符、花括号延伸件 |

因此流水线把**每一页渲染为页面图像**（1224×1584，144 dpi），翻译时逐页对照图像确认公式，文本层只用于正文文字与检索。

## 2. 结构识别与单元切分

从目录页解析出 10 个部分、41 章的起始印刷页码（印刷页 = PDF 页 − 1），据此把正文切分：

- 书名页、引言、10 个部分扉页；
- 第 1–40 章（按章切分，每块 ≤ 8 页，长章再按小节切分）；
- 第十部分附录（922 页，按 "Proof of X.Y" 结构切分）；
- 第 41 章；
- Lean 声明索引（111 页，仅需译章节标题）与参考文献（12 页，保留原文）。

共得到 **237 个翻译单元**，每个单元附带：所属部分/章、PDF 与印刷页码范围、全部页面图像路径、前文/后文语境（仅供理解）。

## 3. 术语与规范

- 《数学术语与语料库》：约 700 条核心英→中术语（黎曼假设与解析数论、代数数论与类域论、自守表示与朗兰兹、Lean 形式化），并收录常见句子模式；各单元翻译中新遇到的术语以 `<!-- NEWTERM: English = 中文 -->` 记录，汇总约 3 300 条，合计约 4 000 条。
- 《翻译规范》：规定公式 LaTeX 写法（`$...$` / `$$...$$`、`\tag`）、定理/引理/定义/证明的加粗标签格式、`Lean: ...` 行原样保留、`<!-- PAGE n -->` 页码注释保留、人名与缩写处理、文风要求（学术中文、不增删、不概括）。

## 4. 并行翻译

每个翻译单元的翻译子代理执行固定流程：

1. 阅读《翻译规范》与《术语表》；
2. 阅读单元源文件（含按页文本层与页面图像路径）；
3. 用图像逐页核对公式，将公式重排为规范 LaTeX；
4. 完整译出全部正文、定理、证明与 Lean 行（不得省略或概括）；
5. 自检页码覆盖与公式完整性。

237 个单元分批并行执行；单单元输出约 3 000–6 000 汉字。

## 5. 统稿与质检

- **术语统一**：对跨单元出现的译名分歧按多数/规范译法统一（如 entry = 矩阵元、thin position = 薄位置、primitive representative = 本原代表元 等）。
- **结构统一**：章节标题按统一的中文标题表规范化；附录中"第 N 章的证明：……"标题与正文章名一致。
- **清理**：删除多余证明结束符（□/∎）、修复数学定界符（删除悬空的 `$$`、修复被误删的单行公式）。
- **自动校验**（237/237 单元）：
  - 每个 `<!-- PAGE n -->` 与源单元逐页对应；
  - `$$`/`$` 定界符平衡；
  - 汉字数/原文字数比值在合理区间（无整段漏译）、无英文残留；
  - 输出 HTML 时汉字零丢失。
- **抽样复审**：20 个单元（覆盖正文与附录）逐页对照页面图像复核，修正 40 余处公式/术语/译文错误（例如 $\nexists$ 与 $\exists$ 的量词反转、$\iota$ 与 $\jmath$ 混用、$2^fk$ 与 $2f^k$ 上下标错误等）。

## 6. 排版与成品

- 中文 Markdown 由自研转换器转为 HTML：处理标题、段落、列表（保留原编号）、定理标签、Lean 行（等宽块）、页码锚点、目录（点线引导 + 右对齐页码）与索引；
- 公式用 MathJax（CHTML 输出）渲染；
- 由于单次渲染 1 500 页会超出浏览器内存，成品按 26 个分块（约 10 个单元/块 + 前置 + 后置）分别打印为 PDF，再合并为 1 182 页的成品；
- 分块渲染同时避免 MathJax 在超大文档上中断导致公式未渲染的问题（本次流水线对此有校验：提取成品 PDF 文本，确保无未渲染的 `$$` 残留）。

## 8. 局限

- AI 辅助翻译，未经人类数学专家审校；
- 全书 2 处 `UNCERTAIN` 标注（原书字形不可辨 / 原书疑为笔误）；
- Lean 索引与参考文献按学术惯例保留原文。
